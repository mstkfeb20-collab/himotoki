# 画面設計書 SC-02 オーナー詳細画面

## 概要

オーナー1名の情報と、飼っているペット・診察履歴を表示する画面。
テンプレートは owners/ownerDetails、表示は GET /owners/{ownerId}。

## 表示項目（オーナー情報）

| 項目 | 物理名 | 備考 |
|---|---|---|
| 氏名 | Owner.firstName + Owner.lastName | |
| 住所 | Owner.address | |
| 市区町村 | Owner.city | |
| 電話番号 | Owner.telephone | |

## 表示項目（ペットと診察）

ペットごとに名前・生年月日・種類、診察日と説明を一覧表示する（Pet、Visit）。

## 操作

- オーナーを編集 → オーナー登録・更新画面
- 新しいペットを追加 → ペット登録画面
