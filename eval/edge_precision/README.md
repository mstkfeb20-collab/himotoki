# つながりの正しさ（抜き取り判定、2026-11-17）

保険契約の題材（sor-bench-g-cr、main）と大規模題材（sor-bench-l、cr01 の親）のグラフ（himotoki ec323ea）から、
CONTAINS 以外の辺を関係の種類×作られ方ごとに最大 8 本・種類ごとに最大 20 本、計 545 本を抜き出し、
himotoki を見ない別エージェント 4 体が実ファイルを開いて判定した（`GUIDE.md`、`result*.json`）。

| | 正しい | 一部（種類・向き・対象テーブルが違う） | 誤り |
|---|---:|---:|---:|
| 545 本 | 486（89%） | 50（9%） | 9（2%） |
| 辺の数で重み付け：保険 | 86.7% | 94.3%（一部込み） | |
| 辺の数で重み付け：大規模 | 68.7% | 98.3%（一部込み） | |

誤り・一部の主因：
- 列名だけで結ぶ（テーブルが書かれていない）参照が、同名の列を持つ別テーブルにも結ばれる。
  設計書の表（大規模で 5,365 本）、resultMap、レイアウト、汎用 XML。大規模題材の重み付きの低さはほぼこれ。
- シェルの `. xxx.sh`（取り込み）を RUNS にしている。実行時の DML を POPULATES にしている。
- テスト名からの推定（XxxTest → Xxx）、メソッドから所属クラスへの REFERENCES、オーバーロードの取り違え。
- 値の流れ：共有の計算部品を経由した誤り 1 本、旧住所と新住所の取り違え 1 本。
- ID の照合：`EDIB030_S02` が `EDIB030` までしか取れず、S01 にも結ばれる。

判定者による揺れ：source 実行を RUNS で可とする判定と不可とする判定が混在。
